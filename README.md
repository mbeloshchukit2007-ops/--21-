# Практична робота: Типи даних та області видимості в JavaScript

## Аналіз та пояснення результатів у консолі (Завдання 1):

1. `"10" + 5` = `"105"` (string) — через дію оператора `+` із текстовим значенням спрацьовує конкатенація (склеювання рядків).
2. `"10" - 5` = `5` (number) — віднімання автоматично примушує JS перетворити рядок у числовий тип.
3. `"10" * "2"` = `20` (number) — оператор множення не працює з текстом, тому обидва рядки приводяться до чисел.
4. `10 + true` = `11` (number) — значення `true` в арифметичних діях розцінюється як `1`.
5. `10 + false` = `10` (number) — значення `false` розцінюється як `0`.
6. `Number("125 грн")` = `NaN` (number) — рядок містить текст, тому функція не може перетворити його на число.
7. `Number("")` = `0` (number) — пустий рядок за правилами JS перетворюється на нуль.
8. `Boolean("false")` = `true` (boolean) — будь-який рядок, у якому є хоч один символ, є істинним.
9. `Boolean("")` = `false` (boolean) — порожній рядок завжди перетворюється на `false`.

## Відповіді на контрольні запитання:

1. **Чому підключення скрипту наприкінці `<body>` (або з атрибутом `defer`) вважається безпечнішим за підключення в `<head>` без цього атрибута?**  
   Браузер читає HTML по порядку. Якщо скрипт у `<head>` без `defer`, він запуститься раніше, ніж браузер створить елементи сторінки, через що скрипт їх не знайде. Підключення в кінці `<body>` гарантує, що вся сторінка вже готова.

2. **Чим відрізняється поведінка оператора `+` від оператора `-` при роботі з рядком, який містить число?**  
   Оператор `+` виконує склеювання рядків (конкатенацію), а оператор `-` перетворює текст на число та віднімає.

3. **Яке значення поверне `10 + true` і чому?**  
   Поверне `11`, оскільки при математичній операції `true` перетворюється на числове значення `1`.

4. **Чому `Number("125 грн")` повертає `NaN`, а `Number("")` — `0`?**  
   `"125 грн"` містить літери, тому JS не може розпізнати це як число. Порожній рядок `""` згідно зі стандартом мови автоматично перетворюється на `0`.

5. **Чому вираз `Boolean("false")` повертає `true`?**  
   У JavaScript будь-який непорожній текстовий рядок є truthy-значенням (істинним), навіть якщо всередині написано слово `"false"`.

6. **Які значення в JavaScript вважаються хибними (`falsy`)?**  
   Хибними є значення: `false`, `0`, `""` (пустий рядок), `null`, `undefined`, `NaN`.

7. **Чим відрізняється область видимості змінної, оголошеної через `var`, від змінної, оголошеної через `let`?**  
   Змінна `var` доступна у всій функції (функціональна видимість), а `let` обмежена блоком фігурних дужок `{ ... }`, де її створили (блокова видимість).

8. **Чому глобальні змінні вважаються небажаними, якщо доступ до них з інших частин коду не є дійсно потрібним?**  
   Вони доступні з будь-якого місця програми, що підвищує ризик випадково перезаписати їхнє значення в іншій функції та отримати помилку.

9. **За яким критерієм варто обирати між `let` і `const` при оголошенні змінної?**  
   Якщо значення змінної буде змінюватися під час виконання коду — використовують `let`. Якщо значення фіксоване — використовують `const`.

10. **Як зміниться доступність змінної, якщо перенести її оголошення з тіла функції в глобальну область видимості?**  
    Вона стане видимою та доступною для читання і зміни з будь-якого місця програми.
